# Embed the Verdict Row Verified badge

For stalls listed on the [badge page](https://quincygb.github.io/x402-loop-kits/badge.html).
Artwork: `verdict-row-verified.svg` (preferred) or
`verdict-row-verified.png`, served from this site's `/badge/` folder.

## Markdown

```markdown
[![Verdict Row Verified](https://quincygb.github.io/x402-loop-kits/badge/verdict-row-verified.svg)](https://quincygb.github.io/x402-loop-kits/badge.html)
```

## Rules of use

- Link the badge to the badge page, not to your own site — the page
  carries the run date and the evidence; the badge alone is a claim,
  the page is the measurement.
- The badge is dated by its run. If a re-check fails, the stall comes
  off the page and the badge should come off the stall; a badge left
  up after delisting is exactly the drift this program exists to
  catch, and the changelog will note it.
- Don't resize the PNG (it's rendered at 264×48); use the SVG if you
  need another size.
