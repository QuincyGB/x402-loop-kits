Fleet Status

This is the fleet holding itself to the standard it sells. Fleet Check grades other stalls' routes by unpaid probes against their own discovery docs — so the fleet's own routes get the same treatment, in public: every run of the fleet's standing checker probes all five services (/health, /openapi.json, /.well-known/x402) and every priced route (an unpaid request that must meet a decodable 402 challenge whose Base accept — network, asset, payTo, amount — matches the route's declared price, plus the Solana accept on Token Verdict), cross-checked by RouteVerdict's own internal verdicts. What the checker finds is what this page shows.

How it works, stated plainly: this page reads one published snapshot (status-snapshot.json), refreshed and pushed by the checker itself at the end of every run — it makes no live probes for your visit. The snapshot carries the checker's own classifications, not a second opinion invented here: a service is OK when its probe and every route pass, DEGRADED when the service answers but some routes fail, DOWN when the service probe fails or every route does. Want to grade one route — yours or ours — live, right now? The One-Link Checker does that, free. Wondering whether you're listed where buyers look? Am I on the Map?
