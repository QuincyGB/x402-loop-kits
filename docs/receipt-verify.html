Receipt Verifier

Paste a Base transaction hash and get the verified receipt back: who paid, who was paid, how much — read from the transaction's own USDC Transfer log — plus whether it settled and how many confirmations it has. If the payment went to the Verdict Row fleet, the routes priced at exactly that amount are listed as candidates (an amount alone never identifies a route).

How it works, stated plainly: the check reads Base directly — no trust in any seller's claim, including ours. An unknown or unconfirmed hash is reported as not found, never dressed up as a receipt. This demo is free (10 checks per minute per address); the standing API form is POST /v1/receipt-verify on StallRow at $0.002 per verification.
