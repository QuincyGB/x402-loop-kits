Known limitations (stated, not hidden)

  • No uptime figure is published, because none is measured. Liveness is probed by the daily integration watch; this page shows the check time behind every LIVE mark.
  • No app-level rate limiting. A flood of well-formed forged payment headers would be forwarded to the facilitator for verification (2026-10-25 audit item M3, accepted risk, open decision). A facilitator-quota check on 2026-10-26 found that CDP's verify performs signature/nonce/balance and KYT screening itself, but no published per-seller verify quota was found in CDP's docs; the Railway-edge option requires dashboard access and has not been applied.
  • Chunked request bodies without Content-Length terminate at the Railway edge; a DNS-rebinding TOCTOU residual exists in the SSRF guards (2026-10-25 audit).
  • EntRoute is parked: its listing gate needs a DNS TXT record that cannot be set on *.up.railway.app, and no custom domain has been purchased.
