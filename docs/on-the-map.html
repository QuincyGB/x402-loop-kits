Am I on the Map?

Buyers find x402 stalls through directories — CDP Bazaar, PayAI, Settled and x402scan. If you are not listed, you are not found, and listings lapse silently. Paste your payTo address or your stall origin URL and see where this snapshot has you.

How it works, stated plainly: this page reads one published snapshot (map-snapshot.json, refreshed when the fleet's catalogue watchdog runs) — it makes no live directory reads for your query. The snapshot is built from the same four directory sources the watchdog reads: bounded slices of the CDP / PayAI / Settled discovery feeds, exact scoped checks for a bounded set of patrol-census origins, and x402scan recipient pages where they were actually fetched (x402scan has no global feed — see the coverage notes under your result). Absence from this snapshot is not absence from a directory: directories change continuously, indexing lags, and a bounded slice cannot see everyone. “Not covered by this snapshot” means exactly that.
